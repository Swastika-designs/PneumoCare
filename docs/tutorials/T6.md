# T6 — Biomedical Image Visualization

**Where in the app:** Image Laboratory → **Visualise** tab (`/image-lab?tab=visualize`) and **Pneumonia Detection**  
**Status:** verified - 3/3 workflow checks passed against the live API (2026-10-28, `scripts/verify_tutorials.py`)

## Objective

Visualise images and model behaviour: comparisons, histograms, overlays, feature maps and Grad-CAM.

## Key concepts

- **Comparison slider.** The original and CLAHE-enhanced images overlaid, with a draggable divider.
- **Histogram and CDF.** Intensity distribution; the cumulative distribution is what histogram equalisation flattens.
- **Pseudo-colour.** Mapping grey levels to a colour map (bone, viridis, inferno, hot, jet). Perceptually uniform maps such as viridis avoid false edges.
- **Overlays.** Canny edges and the lung-field contour drawn on the X-ray; the |CLAHE − original| difference map.
- **Intensity profile.** Grey level along a chosen row: lungs appear as valleys, and the mediastinum and spine as a central peak.
- **Grad-CAM.** Class-activation heat-map from the trained pneumonia model (see `ml_documentation.md`).

## Dataset

PneumoniaMNIST samples or uploads, plus the trained pneumonia checkpoint for Grad-CAM.

## Methodology

The backend renders every panel with OpenCV. Grad-CAM calls the screening endpoint with `context=T6`, so the run counts as T6 (plain predictions on the Pneumonia Detection page do not count as T6 runs).

## Implementation

- Code: `backend/app/services/imaging.py::visualize`, `backend/app/ml/pneumonia/gradcam.py`, `frontend/src/components/images.tsx` (`CompareSlider`, `ImageGrid`), `frontend/src/pages/ImageLab.tsx` (`VisualizeTab`)
- API: `POST /api/imaging/visualize?colormap=&row=`, `POST /api/screening/predict?context=T6`

## Outputs

Six visualisation panels, a comparison slider, a profile line chart, a histogram, and Grad-CAM raw and overlay images.

## Results (actual run, 26 Oct 2026)

Grad-CAM maps are 7×7 (ResNet layer4) upsampled to the image. Measured with the classical lung-field segmentation (`scripts/evaluate_segmentation.py`, 156 test images whose masks pass the plausibility checks), the mean share of Grad-CAM mass inside the lung fields is 0.304, about the same as the lung fields' share of the image (0.316; median ratio 1.11). So the maps do **not** concentrate on the lung fields more than their area would predict. The model may be relying partly on regions outside the lungs, which is an important caveat when you present Grad-CAM. The feature maps from T5 are also visualisations for this tutorial.

## How to run it

Image Laboratory → **Visualise** → **Run**, then **Compute Grad-CAM**. Or upload on the **Pneumonia Detection** page and toggle *show raw map*.

Prerequisites: the backend and frontend are running (see README) and the dataset has been downloaded.

## Limitations

Grad-CAM is coarse and explains the model, not the disease. Colour maps such as jet can create apparent boundaries that are not in the data.
