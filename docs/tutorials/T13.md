# T13 — Dimensionality Reduction for EDA

**Where in the app:** Advanced Analytics → **PCA & EDA** tab (`/advanced?tab=pca`)  
**Status:** verified - 4/4 workflow checks passed against the live API (2026-10-28, `scripts/verify_tutorials.py`)

## Objective

Reduce many correlated variables to a few components and use them for exploratory analysis.

## Key concepts

- **Feature scaling.** PCA maximises variance, so unscaled variables with large units (for example kcal) dominate. z-scoring gives every feature variance 1. Min-max scaling and centring only are offered for comparison.
- **PCA.** Eigen-decomposition of the covariance matrix. Components are orthogonal directions of decreasing variance.
- **Explained variance and scree plot.** The share of total variance per component, and the cumulative curve (with an 80% reference line).
- **Loadings.** Each feature's weight in a component; they show what a component *means*.
- **Scores.** The data projected onto PC1–PC3, shown as a 2-D scatter and a rotatable 3-D scatter, coloured by a categorical variable.

## Dataset

NHANES adults (15 numeric variables, n = 5,120), the Synthea patient profile (26 numeric variables), or an uploaded CSV.

## Methodology

Select numeric columns with > 2 distinct values and ≥ 30% observed → median impute or drop rows → scale → full PCA for explained variance → scores for up to 1,500 sampled points → correlation matrix.

## Implementation

- Code: `backend/app/services/dimensionality.py`, `frontend/src/pages/AdvancedAnalytics.tsx` (`PcaTab`), `frontend/src/components/charts/Scatter3D.tsx`
- API: `GET /api/analytics/pca/sources`, `GET /api/analytics/pca?source=&scaling=&missing=&color_by=`

## Outputs

Scree + cumulative chart, 2-D and 3-D score plots, top loadings per component, loading table, correlation heat-map.

## Results (actual run, 26 Oct 2026)

NHANES, standardised: **8 of 15** components explain 80%. PC1 = diet quantity (energy +0.49, fat +0.45, protein +0.42), PC2 = body size (waist, BMI, weight ≈ +0.54), PC3 = activity vs age/sedentary time. Synthea profile: 12 of 26 components for 80%; PC1 = age and morbidity (conditions, age, QALY, encounters). Without scaling, the first component is almost entirely the largest-unit variable.

## How to run it

Advanced Analytics → **PCA & EDA**. Change the scaling, colour by `bmi_category` or `sex`, and rotate the 3-D plot.

Prerequisites: the backend and frontend are running (see README) and the dataset has been downloaded.

## Limitations

PCA is linear and sensitive to outliers. Median imputation shrinks variance. Components are not causal factors.
