# T11 — Clinical Information Extraction and Entity Recognition

**Where in the app:** Clinical Text → **Entity extraction** tab (`/clinical-text?tab=ner`)  
**Status:** verified - 4/4 workflow checks passed against the live API (2026-10-28, `scripts/verify_tutorials.py`)

## Objective

Extract structured clinical information (problems, medications with doses, vitals, labs, procedures) from free text, including negation.

## Key concepts

- **spaCy pipeline.** Tokenizer → tagger/parser → statistical NER (`en_core_web_sm`: DATE, QUANTITY, …) → our **EntityRuler**.
- **Statistical vs rule-based NER.** General models do not know clinical entities, so the EntityRuler adds lexicon phrases (≈80 problems, 44 medications, 23 labs, 20 procedures, 15 anatomy terms) and token patterns for DOSAGE (`500 mg bid`), VITAL (`BP 138/84`, `HR 112`, `SpO2 91%`), LAB values (`WBC 15.2`) and AGE.
- **Negation (NegEx-style).** A problem is negated if a trigger (`no`, `denies`, `without`, `negative for`, `ruled out`, …) appears within the 6 preceding tokens of the same sentence, unless a terminator (`but`, `however`, …) comes in between. The window lets lists inherit the trigger ("denies chest pain or hemoptysis").
- **Context.** *historical* (`history of`, `s/p`) and *family* (`family history`, `mother`) flags.
- **Structured output.** Problems present/negated, family history, medication–dosage pairs (nearest following dosage in the same sentence), vitals, labs, procedures, as JSON.

## Dataset

Three **synthetic** sample notes written for the project (ED note, outpatient follow-up, discharge summary), any pasted text, and 200 corpus abstracts for statistics at scale.

## Methodology

Load the best available model (`en_ner_bc5cdr_md` if installed, else `en_core_web_sm`, else a blank pipeline + sentencizer) → add the ruler → run → `filter_spans` → context flags → build the structured summary.

## Implementation

- Code: `backend/app/services/clinical_ner.py`, `frontend/src/pages/ClinicalText.tsx` (`NerTab`, `Highlighted`)
- API: `GET /api/text/sample-notes`, `POST /api/text/entities`, `GET /api/text/entity-stats?per_class=`

## Outputs

Colour-highlighted text (negated entities struck through), structured summary + JSON, entity table, top entities per disease class in the corpus.

## Results (actual run, 26 Oct 2026)

ED sample note: 29 entities. Chest pain, hemoptysis and pleural effusion are negated correctly; hypertension and diabetes are flagged historical; all 4 medications are linked to their doses (for example ceftriaxone → 1 g daily); 5 vitals are extracted. Follow-up note: "no fever" after "but" is negated, while the earlier "wheezing" is not; COPD is flagged as family history.

## Limitations

The lexicon is small and hand-made, so recall is limited to listed terms. Negation rules miss complex cases such as double negation or uncertainty ("cannot rule out"). `en_core_web_sm` is not a clinical model. To add statistical clinical NER, install scispaCy's `en_ner_bc5cdr_md` 0.5.x; it is detected automatically.
