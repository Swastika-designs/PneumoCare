# T10 — Clinical Text Classification and Clustering

**Where in the app:** Clinical Text → **Classification** and **Clustering** tabs (`/clinical-text?tab=classify`)  
**Status:** verified - 4/4 workflow checks passed against the live API (2026-10-28, `scripts/verify_tutorials.py`)

## Objective

Preprocess clinical text, classify it with supervised models, and discover structure with clustering.

## Key concepts

- **Preprocessing.** spaCy tokenisation → lower-casing → removal of stop words, punctuation and numbers → lemmatisation (`treated` → `treat`). The UI shows every step.
- **TF-IDF.** Term frequency × inverse document frequency. Common words get small weights and distinctive words large ones. Settings: unigrams + bigrams, sublinear TF, min_df = 2, max_df = 0.9.
- **Classifiers.** Logistic regression, linear SVM and Complement Naive Bayes (Naive Bayes adapted to imbalanced text).
- **Evaluation.** Accuracy, **macro-F1** (each class counts equally), weighted F1, per-class precision/recall/F1, confusion matrix.
- **Clustering.** TF-IDF → Truncated SVD (100 dimensions, the basis of latent semantic analysis) → L2 normalisation → k-means. Internal quality: silhouette. External agreement with the labels: adjusted Rand index (ARI), normalised mutual information (NMI), purity. Elbow plot for choosing k.

## Dataset

Medical Abstracts TC Corpus: 11,550 training and 2,888 test abstracts in 5 classes (neoplasms, digestive, nervous, cardiovascular, general pathological conditions).

## Methodology

Fit each pipeline on the official training split; evaluate once on the test split; save the models (`models/text/classifiers.joblib`) and metrics. Clustering uses a random sample of 3,000 training abstracts.

## Implementation

- Code: `backend/app/services/text_analytics.py` (`preprocess_demo`, `train_classifiers`, `classify`, `cluster`), `frontend/src/pages/ClinicalText.tsx`
- API: `POST /api/text/preprocess`, `POST /api/text/train`, `GET /api/text/metrics`, `POST /api/text/classify`, `GET /api/text/cluster?k=`

## Outputs

Class distribution, model table, confusion matrix, per-class metrics, top terms per class, class probabilities and per-term contributions for your own text, cluster scatter, elbow plot, cluster descriptions, contingency heat-map.

## Results (actual run, 26 Oct 2026)

Test set: Complement NB accuracy **0.586** / macro-F1 **0.578**; linear SVM 0.511 / 0.505; logistic regression 0.499 / 0.491 (chance ≈ 0.23). The *general pathological conditions* class overlaps with all the others, and the published baselines for this corpus are also around 0.6. Clustering with k = 5: silhouette 0.031, ARI 0.055, NMI 0.108, purity 0.41. The clusters capture themes (oncology, cardiology, case reports) rather than the official labels.

## How to run it

Clinical Text → **Classification** → **Train classifiers**, then paste text and press **Classify** / **Show preprocessing**. In **Clustering**, choose k and press **Cluster**.

Prerequisites: the backend and frontend are running (see README) and the dataset has been downloaded.

## Limitations

Hyperparameters are defaults, not tuned (tuning should use cross-validation on the training set, never the test set). Abstracts are not clinical notes. Labels are noisy, and the class 'general pathological conditions' is ambiguous.
