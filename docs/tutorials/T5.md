# T5 — SIFT, RANSAC, and CNN Feature Extraction

**Where in the app:** Image Laboratory → **SIFT · RANSAC · CNN** tab (`/image-lab?tab=features`)  
**Status:** verified - 5/5 workflow checks passed against the live API (2026-10-28, `scripts/verify_tutorials.py`)

## Objective

Detect and match local features, estimate geometry robustly, and extract deep CNN features.

## Key concepts

- **SIFT.** Keypoints are detected as extrema in a Difference-of-Gaussians scale space. Each has a position, scale and dominant orientation, plus a 128-D descriptor (4×4 cells × 8 gradient-orientation bins). This makes them invariant to scale and rotation.
- **Matching.** Brute-force L2 nearest neighbours with **Lowe's ratio test**: keep a match only if the best distance is < ratio × the second-best distance.
- **Homography and RANSAC.** A 3×3 homography maps one image plane to another. RANSAC repeatedly fits it to 4 random matches and keeps the model with the most inliers (reprojection error < threshold), so wrong matches (outliers) are ignored.
- **Known ground truth.** Image 2 is a synthetic warp of image 1 (rotation, scale, translation, perspective) with a known homography. The estimate is scored by the mean error of the four image corners in pixels.
- **CNN features.** An ImageNet-pretrained ResNet-18 used as a fixed feature extractor: feature maps from layer1–layer4 (64×56×56 … 512×7×7) and a 512-D global-average-pooled embedding.
- **Linear probe.** If a simple logistic regression on frozen features separates the classes, the features carry the information, even without fine-tuning.

## Dataset

PneumoniaMNIST samples or uploads. For the embedding map: 150 NORMAL + 150 PNEUMONIA test images.

## Methodology

1. SIFT detection and visualisation of the strongest 300 keypoints; histograms of scale and orientation.
2. Synthetic warp → SIFT on both images → kNN matching with the ratio test → `findHomography` with RANSAC, compared with plain least squares → corner error → visualisation of inliers, outliers and the alignment.
3. Forward hooks on ResNet-18 → the 12 most active channels of the chosen layer as images.
4. Embeddings → standardise → PCA 2-D map; 5-fold cross-validated logistic-regression probe (cached in `models/imaging/feature_embedding.json`).

## Outputs

## Results (actual run, 26 Oct 2026)

`normal_test_0380` with a 15° / 0.9× / perspective-0.05 warp: 94 ratio-test matches, 92 RANSAC inliers, corner error **0.07 px** with RANSAC versus **15.5 px** with least squares. That gap is why RANSAC is needed. Linear probe on frozen ImageNet features: **93.0% ± 2.4%** accuracy, ROC-AUC 0.975 (5-fold CV, 300 images).

## Limitations

X-rays have repetitive rib texture, so SIFT matching between *different* patients is unreliable. Synthetic warps are a controlled test, not real registration. ImageNet features are not specific to X-rays, and the probe is evaluated on only 300 images.
