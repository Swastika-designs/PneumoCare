# T4 — Biomedical Image Analysis

**Where in the app:** Image Laboratory → **Enhance / Restore / Filter / Threshold / Segment / Compress** tabs (`/image-lab`)  
**Status:** verified - 7/7 workflow checks passed against the live API (2026-10-28, `scripts/verify_tutorials.py`)

## Objective

Apply classical image processing to chest X-rays and measure its effect.

## Key concepts

- **Enhancement.** Contrast stretching (2nd–98th percentile → 0–255), global histogram equalisation, **CLAHE** (contrast-limited adaptive equalisation on 8×8 tiles), gamma correction, unsharp masking (1.5·I − 0.5·blur(I)).
- **Restoration.** Add Gaussian, salt-and-pepper or speckle noise, then denoise with Gaussian, median, bilateral or non-local-means filters. Quality is measured against the clean image with **PSNR** (dB) and **SSIM** (structural similarity, 1 = identical).
- **Filtering.** Low-pass (Gaussian, median), first derivative (Sobel gradient magnitude), second derivative (Laplacian), Canny edges (gradient + non-maximum suppression + hysteresis), high-pass (I − blur).
- **Thresholding.** Global, **Otsu** (maximises between-class variance), triangle, adaptive mean and adaptive Gaussian (local thresholds).
- **Segmentation.** Classical lung-field segmentation (no learned model): CLAHE → coarse Gaussian blur so the ribs fade → mediastinum located as the brightest central column band → inverse Otsu, cut along the midline → anatomical rules reject tiny regions, background air, black edge strips, air above the shoulders and bowel gas → **marker-controlled watershed** (eroded lung candidates as seeds; bright tissue, mediastinum and outside air as background) → opening, hole filling, clipping at the midline. Five **plausibility checks** (two fields, total area 15–55%, left/right ratio ≥ 0.4, height ≥ 35%, edge contact < 50% of rows) flag implausible masks. Until 28 Oct 2026 this tab also showed k-means intensity clustering, which groups grey levels and does not identify lungs; it was removed.
- **Compression.** PNG (lossless DEFLATE) vs JPEG (lossy DCT + quantisation) at qualities 95–10, compared by size, compression ratio, PSNR and SSIM.

## Dataset

8 real test-split X-rays from PneumoniaMNIST (`data/sample/xray`, 224×224), or any uploaded image (resized so the longest side is at most 512 px).

## Methodology

Every operation runs on the backend with OpenCV/NumPy, and the images are returned as PNG data URLs with statistics (mean, SD, entropy) and histograms.

## Implementation

- Code: `backend/app/services/imaging.py` (`enhance`, `restore`, `filters`, `threshold`, `lung_fields`, `lung_mask`, `segment`, `compress`, `psnr`, `ssim`), `frontend/src/pages/ImageLab.tsx`, `scripts/evaluate_segmentation.py`
- API: `POST /api/imaging/{enhance|restore|filters|threshold|segment|compress}` (multipart `file` or `sample`, parameters as query strings)

## Outputs

Image panels with captions and metrics, histograms, a restoration metrics table, segmentation steps, a compression table and a PSNR-vs-ratio chart.

## Results (actual run, 26 Oct 2026)

Sample `normal_test_0380`: Gaussian noise σ = 20 gives PSNR 22.1 dB / SSIM 0.34. A 5×5 Gaussian blur restores 31.9 dB / 0.83 (median 31.1 dB). JPEG quality 50 is 10.8× smaller than raw at 38.6 dB; quality 10 is 27.7× smaller at 31.3 dB. Segmentation (`scripts/evaluate_segmentation.py`, 624 test images, **no ground-truth masks, so plausibility only, not accuracy**): masks covering > 60% of the image fell from 71 with the previous heuristic (a corner flood-fill bug) to 2; all plausibility checks pass on 76.1% of images (normal 97.0%, pneumonia 63.6%) versus 54.5% before. On the 8 samples, all 4 normals and 2 of 4 pneumonia cases pass; the two failures are correctly flagged because consolidated lung is not dark.

## How to run it

Open **Image Laboratory**, choose a sample thumbnail or upload an image, open a tab, adjust the sliders and press **Run**.

Prerequisites: the backend and frontend are running (see README) and the dataset has been downloaded.

## Limitations

The segmentation is classical image processing, not a trained or validated lung segmentation model. It finds dark lung fields, so consolidated (white) lung in pneumonia is often missed, and it can fail on rotated or very low-contrast images. The plausibility checks were designed together with the method, so they flag obvious failures but cannot measure accuracy. A pretrained anatomical model (for example torchxrayvision's ChestX-Det PSPNet) was considered but not installed. MedMNIST images are already down-sampled, so fine detail is limited.
