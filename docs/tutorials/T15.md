# T15 — Behavioral Factors Influencing Adult Weight Part 2

**Where in the app:** Advanced Analytics → **Adult weight: models** tab (`/advanced?tab=weight-model`)  
**Status:** verified - 4/4 workflow checks passed against the live API (2026-10-28, `scripts/verify_tutorials.py`)

## Objective

Model BMI (regression) and obesity (classification) from behavioural and demographic factors, evaluate the models, interpret them, and state their limitations.

## Key concepts

- **Target leakage.** Weight, height and waist circumference are **excluded**, because BMI = weight / height² and waist is almost a proxy for BMI. Including them would give misleadingly high scores.
- **Pipeline.** ColumnTransformer: median imputation + standardisation for numeric features, most-frequent imputation + one-hot encoding (first level dropped) for categorical features.
- **Models.** Linear regression and a random forest regressor (BMI); logistic regression and a random forest classifier (obese = BMI ≥ 30).
- **Evaluation.** 80/20 stratified split. Regression: R², MAE, RMSE versus a predict-the-mean baseline. Classification: accuracy, precision, recall, F1, ROC-AUC versus a majority-class baseline. Plus 5-fold cross-validation on the training part.
- **Interpretation.** Linear coefficients (BMI change per 1 SD), logistic odds ratios, and permutation importance (the drop in test R² when a feature is shuffled).

## Dataset

NHANES adults from T14 (n = 5,120): 11 numeric and 4 categorical predictors.

## Methodology

Split → fit the 4 pipelines → test metrics + cross-validation → coefficients and odds ratios → permutation importance (5 repeats) → save to `models/lifestyle/`.

## Implementation

- Code: `backend/app/services/lifestyle.py` (`train_models`, `model_results`), `frontend/src/pages/AdvancedAnalytics.tsx` (`WeightModelTab`)

## Outputs

Regression and classification tables, actual vs predicted scatter, ROC curves, permutation-importance chart, coefficient and odds-ratio tables, limitations.

## Results (actual run, 26 Oct 2026)

BMI regression on the test set: random forest **R² 0.115** (CV 0.100 ± 0.013), MAE 5.2; linear regression R² 0.091; mean baseline R² ≈ 0. Obesity: random forest ROC-AUC **0.699**, accuracy 0.650 (majority baseline 0.582); logistic regression AUC 0.670. Most important features: race/ethnicity, age, sedentary time, alcohol, sex. The non-Hispanic Asian group has much lower odds of obesity (OR 0.20). **Conclusion:** the measured lifestyle factors explain only about 10% of BMI variation. They are associated with weight, but are weak individual predictors.

## Limitations

Associations, not causes. Survey weights are not used in fitting, so results describe the sample. Self-report bias. Single-day diet. Race/ethnicity reflects social and structural factors, not biology.
