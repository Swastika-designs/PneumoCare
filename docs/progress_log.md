## Still incomplete (prioritised)

1. **Grad-CAM does not localise to the lungs** (re-measured on 156 test images on 28 Oct). The model may use
   non-pulmonary cues. A validated lung mask (the current one is classical and has no ground truth) and possibly lung-cropped training would be needed before
   presenting Grad-CAM as evidence of correct reasoning.
2. **Decision threshold transfers poorly.** The validation-chosen threshold (0.029) gives specificity 0.816 on
   test, versus 0.949 at 0.5. Fix with calibration (for example temperature scaling) or threshold selection on
   deployment-like data, not on the test set.
3. **Kaggle dataset not installed** (needs your Kaggle credentials or a browser download). After installing, run
   `scripts/evaluate_pneumonia.py --source kaggle` for a full-resolution check; this is the same test patients, so
   it is not an independent external validation.
4. **No browser-driven tests of button-triggered workflows** (Image Lab, training buttons). Covered via the API and
   unit tests only; a Playwright suite would close this gap.
5. **Statistical clinical NER model not installed** (scispaCy `en_ner_bc5cdr_md`; its installation was blocked in
   this environment). T11 runs on `en_core_web_sm` + rules.
6. T10 hyperparameters are not tuned (logistic regression trails Naive Bayes); T14 has no design-based standard
   errors; Synthea operations data are small (111 patients).
7. **Lung segmentation is classical** and misses consolidated lung; a pretrained anatomical model would need
   to be installed and checked against ground-truth masks.
8. Minor: frontend bundle > 500 kB (code splitting); no DICOM upload; history contains the audit's own test
   inputs (delete `data/pneumocare.db` for a clean demo history).
